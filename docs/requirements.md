# 요구사항 정의서 초안 (회의용)

- 기준: `backend.md` v0.20. 자료가 서로 다르면 피그마 ui 2차 > 팀 회의록 > Notion PRD 순으로 따름. v0.18에는 기능명세 시트와 피그마 현재 화면을 보고 백엔드가 항목별로 정한 것만 더함. v0.19에는 인증을 만들며 정한 것(NFR-12)을 더함.
- 화면 번호는 11-19에 받은 피그마 ui 2차의 번호. 지금 화면은 번호가 다름: 3-4 → 3-3, 3-5 → 3-4, 4-3 → 4-2. v0.18에 고친 줄의 5-3, 7-1~7-3은 지금 화면의 번호.

- 상태: `확정` = 팀 회의, 피그마, 백엔드 결정으로 정해짐 / `제안` = 백엔드 안, 확정 전 / `미정` = 3주차 회의에서 정할 것 / `보류` = 화면이 나오면 다시 봄
